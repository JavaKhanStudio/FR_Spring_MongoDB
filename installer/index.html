Le carnet, en direct — installer

En direct, la plage du carnet suit ce que vous tapez dans votre propre mongosh : un createIndex donne un carnet au gardien, un find montre ce que votre serveur a vraiment lu.

Pas de base sous la main ? Regardez une vraie séance, enregistrée : la plage rejoue ce qu’un vrai serveur a répondu.

4

Démarrer la base du cours et le pont

Le pont lit votre base et sert la capsule sur votre ordinateur. Il n’écrit jamais : son compte peut seulement lire Ficelle_carnet, sa propre base, qui commence avec les 139 tortues de l’histoire. La première fois, Docker télécharge la base : comptez quelques minutes.

cd docker
$env:PONT_DB = "Ficelle_carnet"; $env:PONT_COLL = "turtles"; $env:PONT_SEED = "code/trouver/turtles.json"
docker compose -f docker-compose.yml -f compose.pont.yml --profile simple up -d --build --wait

6

Les tortues chez vous

Les 139 tortues de la capsule tiennent dans un simple fichier JSON. Le pont les charge déjà dans Ficelle_carnet ; ces deux lignes les y remettent à neuf, ou les chargent même sans pont.

Télécharger les 139 tortues

Ouvrez un terminal dans le dossier du fichier téléchargé :

docker cp turtles.json amiraute-mongo:/tmp/turtles.json
docker exec amiraute-mongo mongoimport -u amiral -p amiral --authenticationDatabase admin --db Ficelle_carnet --collection turtles --drop --jsonArray --file /tmp/turtles.json

Si ça ne marche pas tout de suite

La vérification s’arrête au premier problème et affiche une phrase précédée de ✗ : la voici, avec quoi faire.

✗

Docker n'est pas installé sur cet ordinateur.

Docker fait tourner la base de données de l'activité dans un conteneur : une petite machine isolée, déjà prête.

Installez Docker Desktop avec la commande ci-dessous, ouvrez-le une fois depuis le menu Démarrer (il peut demander de redémarrer), puis relancez la vérification :

winget install -e --id Docker.DockerDesktop
pas encore essayée sur Windows

Téléchargez Docker Desktop sur https://docs.docker.com/desktop/setup/install/mac-install/ (Apple ou Intel, selon votre Mac), ouvrez le fichier .dmg, glissez Docker dans Applications, ouvrez-le une fois, puis relancez la vérification.

Installez Docker en suivant https://docs.docker.com/engine/install/ pour votre distribution, puis relancez la vérification.

Fedora :

sudo dnf install -y moby-engine docker-compose
sudo systemctl enable --now docker
pas encore essayée sur Fedora

Debian, Ubuntu, Mint :

sudo apt-get update
sudo apt-get install -y docker.io docker-compose-v2
sudo systemctl enable --now docker

✗

Docker refuse votre compte : il faut faire partie du groupe « docker ».

Un groupe donne un droit à des comptes ; celui-ci donne le droit de lancer des conteneurs.

Ajoutez votre compte au groupe, puis fermez votre session et rouvrez-la (ou redémarrez), et relancez la vérification :

sudo usermod -aG docker $USER
pas encore essayée sur Linux
✗

Docker est installé, mais il ne tourne pas.

Docker doit être démarré pour lancer les conteneurs de l'activité.

Ouvrez Docker Desktop (menu Démarrer, « Docker Desktop ») ou tapez la commande ci-dessous. Attendez que la baleine, près de l'horloge, ne bouge plus, puis relancez la vérification :

Start-Process "$Env:ProgramFiles\Docker\Docker\Docker Desktop.exe"
pas encore essayée sur Windows

Ouvrez Docker (dossier Applications) ou tapez la commande ci-dessous. Attendez que la baleine, en haut de l'écran, ne bouge plus, puis relancez la vérification :

open -a Docker
pas encore essayée sur macOS

Démarrez le service Docker, puis relancez la vérification :

sudo systemctl start docker

✗

La commande « docker compose » ne répond pas.

Docker Compose lance d'un coup les conteneurs que l'activité décrit dans son fichier docker-compose.yml.

Il vient avec Docker Desktop : mettez Docker Desktop à jour (sa roue dentée, « Software updates »), puis relancez la vérification :

winget upgrade -e --id Docker.DockerDesktop
pas encore essayée sur Windows

Il vient avec Docker Desktop : mettez Docker Desktop à jour (menu de la baleine, « Check for updates »), puis relancez la vérification.

Installez le greffon Compose de Docker (https://docs.docker.com/compose/install/linux/), puis relancez la vérification.

Fedora :

sudo dnf install -y docker-compose

Debian, Ubuntu, Mint :

✗

Le port 27017 est déjà pris par un autre programme.

Un port est un numéro de porte sur l'ordinateur : un seul programme à la fois peut écouter derrière chacune, et l'activité a besoin du 27017.

Fermez ce programme, puis relancez la vérification. Si c'est un service MongoDB, arrêtez-le dans un PowerShell ouvert en administrateur (clic droit sur PowerShell, « Exécuter en tant qu'administrateur ») :

net stop MongoDB
pas encore essayée sur Windows

Fermez ce programme, puis relancez la vérification. Si c'est un MongoDB installé avec Homebrew :

brew services stop mongodb-community
pas encore essayée sur macOS

Fermez ce programme, puis relancez la vérification. Si c'est le service MongoDB :

sudo systemctl stop mongod
